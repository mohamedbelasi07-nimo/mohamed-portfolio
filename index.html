02 / HTTP fundamentals

GET & POST

Chapter 2 · Short Answer · Question 4

Question: Compare GET and POST, and state when to use each.

Answer: GET retrieves a resource, commonly includes parameters in the URL query, and should not request a state-changing operation. Use it for searches and reading pages. POST submits data, commonly in the request body, for processing or creating records. Use it for form submissions and changes. Neither method encrypts data by itself; use HTTPS.
