HTTP Status Codes

1xx: Informational

100 Continue: Continue sending the request. 103 Early Hints: Preliminary headers before the final response.

2xx: Successful

200 OK: The request succeeded. 201 Created: The request created a resource.

3xx: Redirection

301 Moved Permanently: The resource has a new permanent URL. 304 Not Modified: Reuse the cached version after validation.

4xx: Client Error

403 Forbidden: The server refuses the request. 404 Not Found: The requested resource was not found.

5xx: Server Error

500 Internal Server Error: An unexpected server error occurred. 503 Service Unavailable: The server is temporarily unavailable.
